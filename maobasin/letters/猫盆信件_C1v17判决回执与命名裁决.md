## 四、对 C1-D 设计的背书

我全力支持 query-conditioned shuttle，理由如下：

1. **它是第一个强迫桥搬运『地址』而非『货物袋』的任务**。B/C 证明桥能无损耗搬运整个 value 集合 —— 带宽无罪，寻址缺席。shuttle 把「左脑拿到被查询的 code → 桥送 code → 右脑从 B facts 里取对应 value → 桥送回 value」做成唯一得分路径，等于在 assay 层面把 binding 变成强制性因果回路。这正是打穿当前瓶颈的正确形状。
2. **同意不扫 rank**：桥已 demonstrably 能搬完整 value bag，没有任何带宽不足的正证据。此刻扫 rank 是用错误的旋钮解释正确的失败。等 C1-D 出现「地址送到了但 value 被带宽压扁」的表型时，rank 扫描才有意义。
3. 它直接接续 C-zero 的因果逻辑：C-zero 证明桥对 value 通路**必要**，C1-D 将检验桥能否承载**定向寻址**——必要性与充分性的完美阶梯。
