# C1-v1.4 诊断报告：四格未逃逸

日期：2026-08-01

执行：K3 / 猫盆实验室

判读：Callosum Nano

## 正式判决

v1.4 的四个格子在预注册的 step-2000 endpoint 均未达到绑定逃逸门槛：

`free_code_acc >= 0.90 AND teacher_forced_value_acc >= 0.90`

组合门槛 `free_chain_exact_acc >= 0.90` 也无人达到。因此预注册归因是：

> 学习率与 full-LM 两个候选解释均不足；转入模型侧结构诊断。Oracle
> 仪器仍未校准，A/B/C 与胼胝体因果判决继续冻结。

## step-2000 endpoint

| cell | LR | full-LM λ | free code | teacher-forced value | free chain exact | 绑定逃逸 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| L1 | 3e-4 | 1.0 | 0.135742 | 0.166992 | 0.020508 | 否 |
| L0 | 3e-4 | 0.0 | 0.141602 | 0.057617 | 0.006836 | 否 |
| H1 | 3e-3 | 1.0 | 0.133789 | 0.107422 | 0.018555 | 否 |
| H0 | 3e-3 | 0.0 | 0.042969 | 0.047852 | 0.004883 | 否 |

这些数值来自各格 `metrics.jsonl` 的 step 2000，而不是 best checkpoint。这个区别
对 H0 尤其重要：其 `result.json` 的 `best_step` 是 1800，但正式判读正确使用了
2000 endpoint。

## 可以说什么

1. 10 倍学习率没有促成逃逸；在本 seed、本架构下，3e-3 反而不优于 3e-4。
2. 没有看到 full-LM 干扰。λ=1 在两个学习率下都提高了 teacher-forced value
   与 chain exact；它可能通过 B 事实中的 value token 提供了辅助监督。
3. 上述第 2 条只是一条单 seed 的描述性趋势，不是一般性主效应。低学习率下
   L0 的 free code 0.141602 仍略高于 L1 的 0.135742，因此不能写成“λ=1
   全指标更好”。
4. given-4 仍约等于四选一随机水平（四格 0.237--0.271），与“值集合在场、
   键值绑定没有形成”相容。

## K3 的辅助校准

K3 另在猫盆模型上报告：同格式、64 IDs、grad clip 1.0 的任务会在约
1600--2000 步发生先绑定、后组合的两段式相变。这是支持“2000 步预算足够、
继续查模型侧”的重要外部证据，但相应原始曲线不在本次结果 zip 中，所以这里
将其列作辅助校准，不与 v1.4 四格的正式证据混写。

剩余候选包括 branch width / heads、位置编码、weight decay、层数与共享 token
interface。v1.5 将用单因素格加一个近似猫盆结构的阳性控制继续定位。
