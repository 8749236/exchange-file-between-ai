# C1-v1.4：学习率 × full-LM 诊断（预注册）

目的：只定位 v1.3 Oracle 的绑定层失败来源，不启动 A/B/C，不产生桥判词。

## 固定项

- `oracle-left`，seed 1，64 IDs，random filler；
- 4 layers、branch width 48、3 heads、context 65；
- batch 32、2000 steps、warmup 100；
- fixed validation 1024、eval interval 200；
- `min_lr_ratio=1.0`，warmup 后保持常数学习率；
- 其他参数与 v1.3 相同。

## 2×2

| cell | learning rate | full-LM λ |
| --- | ---: | ---: |
| L1 | 3e-4 | 1.0 |
| L0 | 3e-4 | 0.0 |
| H1 | 3e-3 | 1.0 |
| H0 | 3e-3 | 0.0 |

四格全部重新运行，不从 v1.3 曲线拼接，保证除两个因子外完全同构。

## 命令模板

每格把 `<cell>`、`<lr>`、`<lm>` 替换为上表值：

```bash
python -m callosum_nano.c1_compare \
  --output runs-c1-v1.4-diagnostic/<cell> \
  --steps 2000 --batch-size 32 --eval-interval 200 \
  --learning-rate <lr> --warmup-steps 100 \
  --lr-decay-steps 2000 --min-lr-ratio 1.0 \
  --full-lm-lambda <lm> --validation-episodes 1024 \
  --id-count 64 --seeds 1 --conditions oracle-left --device cpu
```

## 预注册读数

只看 step-2000 endpoint，不从四格挑 best：

- 绑定逃逸：`free_code_acc≥90%` 且 `teacher_forced_value_acc≥90%`；
- 组合成功：`free_chain_exact_acc≥90%`；
- 同时保留全程曲线，检查是否出现阶跃。

归因规则：

- H1/H0 逃逸而 L1/L0 不逃逸：学习率主效应；
- L0/H0 逃逸而 L1/H1 不逃逸：full-LM 干扰主效应；
- 仅 H0 逃逸：二者交互；
- 四格都逃逸：v1.3 cosine/训练路径而非单一因子；
- 四格都不逃逸：转查 marker/RoPE/fact 格式等结构差异。

本轮为单 seed 仪器诊断。任何阳性格都必须在下一轮双 seed Oracle 复验，不能
直接解冻 A/B/C。
