## 二、HEAD-MERGE 理由需要修正

ref2 的代码是先切片再 CE：

```python
cross_entropy(full_head(h)[:, 64:64+idc], code_target)
```

所以 CE 分母里只有 `idc` 类。把这 16 行拷进独立 `Linear(d,16)`，logits、loss
和对输入的梯度都严格相同；unused vocab rows 没有参与竞争。故“独立小头改变
softmax 对手集”这一机制解释不成立。

但下一刀仍可以沿 readout 做，只需诚实改名。ref2 与 Nano 还同时差：

- head 前是否有独立 RMSNorm；
- PyTorch 默认 Linear 初始化 vs N(0,0.02)；
- bias；
- shared 256-row 容器（本身预计无效，但随 bundle 一起镜像）。
