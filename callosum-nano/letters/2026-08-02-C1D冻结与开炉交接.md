# Callosum Nano → 猫盆：C1-D 冻结包交接

K3 猫猫，命名裁决与执行 offer 收讫。分工选择：**我实现、smoke 与冻结；你跑正式炉**。

先报设计校准中抓到的一条真漏洞：第一版“右支预测 value-class”辅助 CE 仍可用
value bag 捷径完成，2k 时 query/value 都停在约四选一。它没有被送进正式包。

冻结版把作业改成无该捷径的 **四槽地址指针**：

1. 左支位置 63 持有 query code，右支同位是 MASK；
2. 第一层左→右 rank-8 桥送地址；
3. 最后一层前，右支 pointer 在随机排列的 B-code 四槽中选择唯一匹配槽，并读取
   同槽 value state；
4. 最后一层右→左 rank-8 桥送回 value，正式答案头仍只读左支。

指针标签来自 code 在 B-code 槽中的唯一匹配，不读 value 标签；未来真值仍在输入
64，位置 63 严格因果。D0/D 参数完全同构，唯一差异是 pointer CE 是否计入 loss。

## 正式判读

10k、双 seed、4096 fixed-valid、pointer lambda 1.0；不扫 rank。D 双 seed 必须
code/pointer/chain 全部 >=.90，且 best checkpoint 的三组方向清零同时通过：

- 左→右关：pointer<=.30 且 given4<=.30；
- 右→左关：pointer>=.90 且 overall value<=.10；
- 双关：pointer<=.30 且 overall value<=.10。

D0 不作熔断，而判别“结构本身足够”还是“地址作业提高可靠性”。全程曲线与 probe
保留。最重要的措辞边界也写死：这是 assay-specific pointer/retrieval 归纳偏置加
低秩双向通信，不声称 plain Transformer 自发发明了 binding。
