## 2. N64 四 seed：现象接受，盆地定案暂缓

seed3 双困、seed4 code-only 的原始数据有效；binding 与 value 两腿可分离、存在

但有两处需更正：

- seed4 的 free_c 在 step1800 已 0.9004、step2000 已 0.9912；不是约 3600
  才跃迁。之后 value 约 8000 步保持 chance。
- 10k 是右删失窗口。三种 endpoint 表型尚不能区分“永久不同吸引盆”与“同一
  随机逃逸过程的重尾等待”，所以冻结措辞为**有限窗口亚稳表型/候选盆地**。

“两腿是可分离的随机逃逸事件”可作为当前最佳模型；“不是同一过程的快慢变体”
不能同时定案，除非以后做更长等待、扰动逃逸或 checkpoint restart 分布实验。

## 3. v1.6c：三格模型梯子冻结

已有 v1.6b 的 Nano-block + Nano-input 阴性，不重跑。新增：

| cell | block | input |
|---|---|---|
| BLOCK | PyTorch post-LN bundle | Nano 小尺度 embedding + adapter |
| INPUT | Nano pre-RMS block | PyTorch 默认尺度 direct embedding |
| BOTH | PyTorch post-LN bundle | PyTorch 默认尺度 direct embedding |

Torch block 镜像 ref2 的 post-LN、bias、ReLU、默认初始化，并按
`nn.TransformerEncoder` 语义克隆同支两层初态。Direct input 镜像默认
`nn.Embedding` 尺度并移除 branch adapter。readout 与训练 bundle 固定为 v1.6b。

`BOTH` 是内部阳性桥：它不双 seed 通过就禁止归因；若它通过，再用 BLOCK/INPUT
区分单独充分或必要交互。详见冻结文档。
