# C1-v1.6c：block × input 模型梯子（冻结）

日期：2026-08-01

## 前置判决

v1.6b 的 `shared-vocab-plain` readout bundle 在 N16/4k 双 seed 均未相变，故
readout bundle 不足以解释 Nano 与 ref2 的差异。N64/20k 与 A/B/C 继续冻结。

## 两个 bundle

**Nano block**：pre-RMS、bias-free attention/MLP、GELU、Nano N(0,0.02)
projection 初始化。

**Torch block**：`nn.TransformerEncoderLayer` 的 post-LayerNorm、biased
projections、ReLU 与 PyTorch 默认初始化；同一分支的两层初态按
`nn.TransformerEncoder` 语义克隆。

**Nano input**：token/position embedding N(0,0.02)，再经 bias-free
N(0,0.02) adapter 投影到 branch。

**Direct input**：token/position embedding 使用 PyTorch `nn.Embedding`
默认初始化，且 `interface_width == branch_width` 时直接进入 block，无 adapter。

readout 固定为 v1.6b 的 `shared-vocab-plain`；训练 bundle 固定为 M/ref2 风格。

## 三格（第四格已有）

| cell | block | input | 状态 |
|---|---|---|---|
| NN | Nano | Nano | v1.6b 已测：阴性，不重跑 |
| BLOCK | Torch | Nano | 本炉 |
| INPUT | Nano | Direct | 本炉 |
| BOTH | Torch | Direct | 本炉内部阳性桥 |

共同配置：Oracle-left、exact chain-two-hop、N16、random filler、2L/64w/2h、
learned positions、batch64、lr3e-3、warmup1、constant LR、WD0、clip1、
full-LM 0、4000 steps、validation1024、seeds1/2。

## 门与判读

每格双 seed 的 step-4000 endpoint 均须同时满足 free code、free given-4 value、
free chain exact ≥0.90，才记作该格通过。

| BLOCK | INPUT | BOTH | 判读 |
|---|---|---|---|
| 通过 | 未过 | 通过 | block bundle 单独足以救活 |
| 未过 | 通过 | 通过 | input/adapter+scale bundle 单独足以救活 |
| 未过 | 未过 | 通过 | 两 bundle 存在必要交互 |
| 通过 | 通过 | 通过 | 两 bundle 各自均足以救活；后续分别拆包 |
| 任意 | 任意 | 未过 | 内部阳性桥失败；不得作 block/input 归因，先审与 ref2 剩余差异 |

任何单 seed 分裂都按该格未过记录，同时保留为种子敏感性诊断。不延长、不挑 best、
不自动启动下一炉。

## N64 四 seed 的边界

10k 截止时观察到全收敛、双腿未逃逸、code-only 三种表型，支持两条腿可分离且
存在长寿命亚稳态；有限窗口不能区分永久不同吸引盆与更长的重尾逃逸等待。
seed-4 的 code 跃迁发生在 step 1800–2000，之后 value 约 8000 步保持 chance，
不是 step 3600 才跃迁。
