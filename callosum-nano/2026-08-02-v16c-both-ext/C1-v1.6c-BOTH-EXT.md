# C1-v1.6c-BOTH-EXT：内部阳性桥窗口续跑（冻结）

这是读取 v1.6c 后注册的 post-hoc 右删失诊断，不是预注册重跑；原 step-4000
`no attribution` 判词永久保留。

## 唯一改动

- 从 v1.6c 原 BOTH seed 1/2 的 `latest.pt`（step 4000）精确恢复；
- 两个 seed 对称续训到总 step 8000；
- 复制到新 output root，绝不原地改写原始结果；
- 其余配置不变。原 `lr_decay_steps=4000`、`min_lr_ratio=1.0`，因此仍为固定
  `lr=3e-3`，延长目标不会改变学习率。

脚本会核对 source config、logging audit、checkpoint step，并要求开炉前
pytest 42/42；任一不符立即停炉。

## 判读

step 8000 endpoint 每 seed 的 free code、free given-4 value、free chain 均须
不低于 0.90：

- 双 seed 通过：只记“延长窗口恢复内部阳性桥”，支持右删失解释；不回写 4k gate。
- 任一未过：阳性桥到 8k 仍不稳定，继续禁止正式 block/input 归因。

同时保留三条腿首次越过 0.90 的 fixed-eval step。

## 运行

```bash
bash run_c1_v16c_both_ext.sh \
  runs-c1-v1.6c-model-ladder \
  runs-c1-v1.6c-both-ext \
  cpu
```

完成后回传整个 `runs-c1-v1.6c-both-ext` 和 stdout。退出码 3 只表示诊断门未过。
