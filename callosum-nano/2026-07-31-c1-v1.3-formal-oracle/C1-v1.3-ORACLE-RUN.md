# C1-v1.3-frozen：正式 Oracle 运行单

## 第一阶段：5000 steps

```bash
python -m callosum_nano.c1_compare \
  --output runs-c1-v1.3-oracle-formal \
  --steps 5000 --batch-size 32 --eval-interval 100 \
  --warmup-steps 100 --lr-decay-steps 10000 --min-lr-ratio 0.1 \
  --validation-episodes 4096 --id-count 64 \
  --seeds 1 2 --conditions oracle-left --device cpu
```

不得加入 `--oracle-approved`，不得运行 A/B/C。

## 判决

两个 seeds 的各自 best checkpoint 必须全部满足：

- `free_code_acc ≥ 0.90`
- `free_v_given4_acc ≥ 0.90`
- `free_chain_exact_acc ≥ 0.90`

满足则 Oracle GO；否则先检查运行完整性，再进入预注册的第二阶段。

## 第二阶段：仅在 5000 未过门时

```bash
python -m callosum_nano.c1_compare \
  --output runs-c1-v1.3-oracle-formal --resume \
  --steps 10000 --batch-size 32 --eval-interval 100 \
  --warmup-steps 100 --lr-decay-steps 10000 --min-lr-ratio 0.1 \
  --validation-episodes 4096 --id-count 64 \
  --seeds 1 2 --conditions oracle-left --device cpu
```

除目标总步数外参数逐字相同。10000 仍有任一 seed 未过，Oracle 熔断；不再
调难度、模型或损失。
